Снимок состояния на момент аудита — не обязательства, фиксация находок,
чтобы не потерять. Сверено по коду, не по ROADMAP.md (который местами

## Блокер №1 — содержательный, не технический

`README.md:7-10` прямым текстом: **"Статус: разработка, до релиза v1.0.
Публичный независимый security-аудит крипто-части ещё не проведён ... не
используйте для данных, утечка которых представляет реальный риск, до
появления такого аудита."**

Продавать за деньги шифрованное хранилище, которое само предупреждает
"не доверяйте ему реальные данные" — репутационный и потенциально
юридический риск: платный продукт создаёт ожидание гарантии выше, чем
"пока непроверенный код". Нужно либо провести/заказать независимый аудит,
либо осознанно менять позиционирование до монетизации.

## Технический чеклист — Android / Play Console

### Готово
- `compileSdk`/`targetSdk = 36`, `minSdk = 24` (`android/app/build.gradle.kts`)
  — современно, свериться на момент реальной публикации, что 36 не
  preview-уровень.
- Подпись настроена по-настоящему: `android/release.keystore` +
  `android/keystore.properties` локально (не в git), через
  `secrets.ANDROID_KEYSTORE_*` в CI.
- AGP `8.7.3` — поддерживает всё нужное, включая `bundleRelease`.
- `android:allowBackup="false"` в манифесте — правильно для security-приложения.
- Permissions в манифесте обоснованы комментариями и `<property>`-описанием
  для `FOREGROUND_SERVICE_SPECIAL_USE` — хорошая база для объяснения
  Google при ревью.

### Не хватает (нужно сделать)
- **CI собирает только APK** (`./gradlew assembleRelease`,
  `.github/workflows/release.yml`) — Google Play с августа 2021 требует
  **AAB** для новых приложений. Нужно добавить `bundleRelease`
  и загружать `.aab`.
- **Иконка — заглушка.** `drawable/ic_launcher_foreground.xml`: *"Временная
  заглушка-иконка ('C' в круге) — Фаза 14, реальный дизайн не делался, это
  отдельная непрограммистская задача."* Нужен реальный дизайн перед платным
  листингом.
- **Store-ассетов нет вообще**: hi-res иконка 512×512 PNG, feature graphic
  1024×500, минимум 2 скриншота телефона (желательно 4-8) — всё с нуля.
- **Privacy Policy отсутствует.** Обязательный URL в Play Console. Писать
  несложно — собирать почти нечего: GitHub API для проверки обновлений +
  опциональный веб-доступ (оба уже честно описаны в манифесте/README),
  больше приложение никуда ничего не шлёт.
- Короткое (≤80 симв.) и полное (≤4000 симв.) описание для листинга — есть
  хороший исходный материал в `README.md`, но текст под формат стора не
  написан.

### Стоит пересмотреть
- `isMinifyEnabled = false` — без R8-шринкинга/обфускации. Не блокер, но
  для security-приложения стоит включить (плюс чуть меньше размер AAB).
- `versionName = "0.1.0"`, `versionCode = 1` (`defaultConfig`) — при этом
  история коммитов называет это "Фаза 18 (релиз v1.0)". Несогласованность
  с тем, что реально увидит пользователь в сторе — решить, что показывать.
- Нет `mipmap-hdpi/xhdpi/...` растровых PNG помимо vector-фолбэка для API
  24-25 — сам fallback существует и помечен комментарием как осознанный
  (`mipmap/ic_launcher.xml`), технически работает, но это тот же
  placeholder-дизайн, что и выше.

## Юридическое / процесс публикации

- **Content rating (IARC-анкета)** и **Data Safety-анкета** — формы,
  которые проходятся при самой подаче, не то, что лежит в репозитории.
  Для Data Safety декларировать ровно два сетевых обращения (GitHub API
  проверки обновлений, опциональный веб-сервер), не больше.
- **Export compliance self-classification** — нужно реально подать как
  разработчик (ежегодно), криптография — основная функция продукта, не
  просто TLS.
- **AGPL-3.0** разрешает продавать копии программы (разовая оплата за
  сборку/удобство — законно по GPL/AGPL). Раз исходники публичны на
  GitHub — отдельного "письменного предложения исходников" по AGPL не
  требуется. Разумно явно сослаться на исходники в описании в сторе, чтобы
  не выглядело как продажа закрытого кода.
- **Closed testing** — 12 тестеров, непрерывно подписанных 14 дней (если
  личный Play Console аккаунт создан после 13.11.2023) — нужно заранее
  найти реальных людей, прохождение теста не гарантирует одобрение.
- **Merchant account** — т.к. разработчик не резидент России, обычная
  процедура (бизнес-данные, банк), но не мгновенная — закладывать время
  на верификацию.
